# P2 會員 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 會員功能（註冊 → 登入 → 會員中心、忘記密碼、Google 登入）從前端能完整操作且安全，修掉設計列出的帳號接管漏洞，主線有 E2E，最後寫 P2 報告、合併、打 tag。

**Architecture:** DB 用一個 versioned migration 讓 `user.password` 可為 NULL、加 `lower(email)` 唯一索引。後端新增 `src/utils/authToken.js` 集中簽發 / 驗證 token：登入 token 與重設 token 都帶「密碼指紋」`pwv`，`auth.js` 每次查 DB 比對，密碼一變舊 token 全失效。驗證碼改成 HMAC cookie。前端維持 hash 模式，修路由、登入檢查、外部回跳網址。測試沿用總覽 repo 的 pytest，新增 Playwright Python E2E 於 `e2e/`。

**Tech Stack:** Express 4.21 + raw `pg`、PostgreSQL 15、Flyway 10.20.1、Vue 3 + Vite（hash router）、Python / uv / pytest 8.3.3 / requests / psycopg 3 / PyJWT、新增 pytest-playwright。

**Spec:** `docs/superpowers/specs/2026-11-12-p2-member-design.md`（以下稱「P2 spec」）；上位 `docs/superpowers/specs/2026-10-15-tripeasy-rebuild-design.md`（「總 spec」）。契約：`docs/db-contract.md`。

### 共用約定（多個 Task 引用，值不得更改）

| 名稱 | 值 |
|---|---|
| 密碼指紋 `pwv` | `HMAC-SHA256(key = JWT_SECRET, msg = password ?? '')` 的 hex 前 16 字元；`password` 是 `user.password` 欄位原值（bcrypt 字串或 NULL） |
| 登入 token payload | `{ id, role, typ: 'login', pwv }`，效期 `JWT_EXPIRES_DAY` |
| 重設 token payload | `{ id, typ: 'reset', pwv }`，效期 `15m` |
| NULL 密碼 Email 登入 | HTTP 401，訊息 `此帳號使用 Google 登入，請改用 Google 登入，或透過忘記密碼設定密碼。` |
| NULL 密碼會員中心改密碼 | HTTP 400，訊息 `此帳號尚未設定密碼，請透過忘記密碼設定。` |
| email 重複 | HTTP 409，訊息 `Email已被使用`（沿用現有） |
| migration 檔 | `backend/migrations/V3__p2_user_auth.sql` |
| email 唯一索引名 | `user_email_lower_key` |
| 驗證碼 cookie | 名稱 `captcha`；值 `<expiresMs>.<hex HMAC-SHA256(key = CAPTCHA_SECRET, msg = lower(answer) + '.' + expiresMs)>`；5 分鐘 |
| 新環境變數（寫入 `.env.example`） | `CAPTCHA_SECRET=local-captcha-secret-change-me`、`COOKIE_SAMESITE=Lax`、`COOKIE_SECURE=false`、`CORS_CREDENTIALS=true` |
| 移除的環境變數 | `DEFAULT_OAUTH_PASSWORD`（程式與 `.env.example`） |
| 重設信連結 | `${FRONTEND_PATH}/#/admin/resetpw?token=<reset token>` |

## Review Focus

1. **既有測試自己簽的 JWT 會全部失效。** `tests/conftest.py:auth_header` 簽 `{id, role}`，`test_api_smoke.py` 等大量依賴；加上 `pwv` 檢查後若沒跟著改，整個 suite 會變 401。→ Task 4 改 `auth_header` 並跑全套 suite。
2. **大小寫不同的 email 登入既有小寫帳號**：使用者註冊 `alice@x.com`、登入打 `Alice@X.com` 應該成功，不是 401。→ Task 2 `test_login_email_is_case_insensitive`。
3. **token 指向已刪除的會員**：`auth.js` 查不到人時要回 401，不能 500。→ Task 4 `test_token_of_deleted_user_is_401`。
4. **Google 會員（NULL 密碼）走忘記密碼**：重設 token 的 `pwv` 由 NULL 算出，必須能正常完成重設，之後 Email 登入成功。→ Task 4 `test_null_password_user_can_set_password_via_reset`。
5. **改完密碼的當下 session**：自己的舊 token 也會失效，前端不能卡在錯誤畫面，要導回登入頁。→ Task 9 E2E `test_change_password_redirects_to_login`。
