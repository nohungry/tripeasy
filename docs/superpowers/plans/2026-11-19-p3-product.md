# P3 商品 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> 狀態：**草稿**（2026-11-19，待使用者審閱 spec 與本計畫後才開工）

**Goal:** 商品功能（首頁清單、搜尋、詳情、評論、隱藏玩法）從前端能完整操作；新增「只有購買過的會員能寫評論、分享隱藏玩法」；修掉讀取 API 與前端的既有問題、處理 P1／P2 指派的待辦；主線有 E2E；最後寫 P3 報告、合併、打 tag。

**Architecture:** DB 用一個 versioned migration `V4` 給 `review` 加部分唯一索引與評分 CHECK。後端新增 `src/utils/purchase.js`（`hasPurchased`／`hasReviewed`，一條 `EXISTS` 查 `orders`＋`order_item.payment_status = 1`），由三支新 API（資格查詢、寫評論、分享隱藏玩法）共用；既有讀取 API 修分頁、篩選、詳情 404、促銷期間。前端在 `utils/api.js` 統一處理 401（「登入已過期」）與公開頁的過期 token 重試，首頁、搜尋頁、詳情頁改接 API，移除假頁面路由。測試沿用總覽 repo 的 pytest 與 Playwright Python，新 fixture `make_tour`／`make_order` 直接寫訂單（結帳在 P4）。

**Tech Stack:** Express 4.21 + raw `pg` + Joi 17、PostgreSQL 15、Flyway 10.20.1、Vue 3 + vue-router 4.5（hash history）+ Vite + axios + sweetalert2、Python 3.13 / uv / pytest 8.3.3 / requests / psycopg 3.2.3 / PyJWT / pytest-playwright 0.5.2。

**Spec:** `docs/superpowers/specs/2026-11-19-p3-product-design.md`（以下稱「P3 spec」）；上位 `docs/superpowers/specs/2026-10-15-tripeasy-rebuild-design.md`（「總 spec」）。契約：`docs/db-contract.md`。前一階段：`docs/reports/phase-2.md`（「P2 報告」）。

## Review Focus

1. **購買資格只認「本人、本行程、`order_item.payment_status = 1`」。** 未付款（-1、0）、已取消（2）、已退款（3）、逾時（4）、別人的訂單、別的行程的訂單都不能寫。→ Task 6 `test_post_review_unpaid_status_is_403`、`test_post_review_other_users_order_does_not_count`、`test_post_review_order_for_other_tour_does_not_count`、`test_eligibility_seed_alice`；Task 7 `test_post_hidden_share_unpaid_status_is_403`。
2. **檢查順序固定**（401 → 角色 403 → 400 → 404 → 未購買 403 → 409）。→ Task 6 `test_post_review_admin_with_invalid_body_is_403`、`test_post_review_validation_before_purchase_check`、`test_post_review_unknown_tour_is_404`。
3. **重複評論在併發下只寫入一則**，且不出現 500。→ Task 5 `test_review_duplicate_user_tour_rejected`；Task 6 `test_post_review_concurrent_only_one_succeeds`。
4. **XSS**：`javascript:` 等網址被擋；HTML 內容原樣保存、頁面以文字顯示不執行。→ Task 7 `test_post_hidden_share_validation`；Task 6 `test_post_review_html_stored_verbatim`；Task 12 E2E `test_review_html_rendered_as_text`、`test_hidden_share_rejects_javascript_url`。
5. **過期 token**：公開頁照常顯示並提示登入已過期；會員操作導回登入頁且不再跳後端錯誤框。→ Task 8 `test_session_expired_on_member_api_shows_message`；Task 9 `test_detail_with_expired_token_still_renders`；Task 10 `test_home_with_expired_token_lists_products`；Task 12 `test_review_submit_with_expired_token`。
6. **搜尋分頁完整、不重複**。→ Task 3 `test_search_pages_cover_every_listed_tour_once`；Task 11 E2E `test_search_pagination_visits_every_listed_tour_once`。
7. **PATCH `/info` 部分更新不能清掉另一欄。** → Task 2 `test_patch_profile_info_name_only`（加斷言偏好不變）、`test_patch_profile_info_preference_only`。
8. **殘留清除不能刪到 seed 或非測試帳號。** → Task 1 `test_purge_removes_only_test_data`、`test_purge_prefixes_cover_fixture_emails`。
9. **Swal 改 timer 不能讓 P2 流程退化。** → Task 8 `test_login_success_ok_closes_and_redirects_immediately`、`test_signup_success_ok_redirects_immediately`，並跑全套 E2E。
